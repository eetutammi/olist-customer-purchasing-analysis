# Data

This project uses the **Olist Brazilian E-Commerce Public Dataset**.

The dataset contains information about:

- customers
- orders
- order items
- products
- product categories
- reviews
- sellers
- payments
- delivery dates

The raw dataset is not included in this repository.

The dataset is publicly available from Kaggle:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Download the dataset and place the CSV files in this `data/` directory before running the analysis.

The analysis uses the original Olist dataset files without modifying the raw data.
